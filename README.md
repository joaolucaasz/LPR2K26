# 👨‍💻 Desenvolvimento de Sistemas - Estudos em C# e C++

## Sobre este repositório

Este repositório reúne os projetos, exercícios e atividades desenvolvidos durante meu curso de **Desenvolvimento de Sistemas (DS)**.

Atualmente, estou aprendendo os fundamentos da programação utilizando as linguagens **C#** e **C++**, desenvolvendo a lógica de programação, algoritmos, estruturas de controle, orientação a objetos e outros conceitos essenciais para a formação como desenvolvedor.

## Objetivo

O objetivo deste repositório é documentar minha evolução durante o curso, registrando os exercícios, desafios e projetos realizados ao longo das aulas.
